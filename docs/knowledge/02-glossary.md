# 02. Доменный словарь (глоссарий)

> Составлен по определениям из документов легаси. Источники в скобках. Где термин уточнён отраслевой практикой (Белов) — метка **[Г]**. Единый язык (Эванс) — используем эти слова в требованиях и в UI.

## Участники договора

| Термин | Определение | Комментарий аналитика |
|--------|-------------|----------------------|
| **Страхователь** | Физ- или юрлицо, заключающее договор страхования и уплачивающее взносы `[ист: 08_module_osago.txt]` | Тот, кто платит и подписывает |
| **Собственник** | Владелец ТС (может отличаться от страхователя) `[ист: 08_module_osago.txt §5.1.4]` | В ОСАГО есть чекбокс «Собственник является страхователем» → автозаполнение |
| **Застрахованный** | Лицо, чьи риски покрывает полис (в «Здоровье») `[ист: 07_module_health.txt]` | Чекбокс «Страхователь = Застрахованный»; в коллективном полисе — до 50 |
| **Водитель** | Лицо, допущенное к управлению ТС (ограниченный список 1–5 или без ограничений) `[ист: 08_module_osago.txt ФТ-22]` | Может быть = страхователь / = собственник / иное лицо |
| **Страховой агент** | Продаёт полисы от имени СК `[ист: 08_module_osago.txt]` | **Главный пользователь системы** |
| **Субагент** | Работает под агентом по договору `[ист: 09_module_renewal.txt]` | Для ИП/ЮЛ со штатом |
| **Куратор** | Управляет агентами, связь агент↔СК `[ист: 08_module_osago.txt §3.1]` | Демо-куратор: Парфенова Оксана Анатольевна |

## Идентификаторы

| Термин | Определение |
|--------|-------------|
| **ИКП** | Индивидуальный код продавца (агента) `[ист: 08_module_osago.txt]`. **Внимание:** в отчёте Сколково однажды расшифрован как «Индивидуальный Код Предпринимателя» `[ист: 10_skolkovo_report.txt §3.9.1]` — **расхождение**, каноничен «код продавца» (см. CLAUDE.md). Атрибут агента, не строки таблицы |
| **VIN** | 17-значный идентификационный номер ТС `[ист: 08_module_osago.txt]` |
| **Гос.номер / ГРЗ** | Государственный регистрационный знак ТС |
| **СТС** | Свидетельство о регистрации ТС (ГИБДД) |
| **ПТС / ЭПТС** | Паспорт ТС (бумажный / электронный, 15-значный код) |
| **ПСМ / ЭПСМ** | Паспорт самоходной машины (для категории «F» / «Техника») |
| **ВУ (В/У)** | Водительское удостоверение |
| **ИНН / КПП / ОГРН** | Реквизиты юрлица (страхователь ЮЛ) |
| **№ полиса** | Уникальный номер договора; для ОСАГО — канонический формат (в прототипе `osagoPolicyNumber()`), для НС — `001SHG-XXXXXX/ГОД-AKN` |
| **№ заявки / № расчёта / № котировки** | Внутренние идентификаторы операций (см. ниже «Котировка») |

## Расчёт и коэффициенты ОСАГО

| Термин | Определение | Комментарий |
|--------|-------------|-------------|
| **Котировка** | Данные о страхователе, которые передаём в СК-партнёра для расчёта `[ист: 08_module_osago.txt]`. **Для каждой СК — своя котировка** (свой набор данных и свой ответ) `[ист: 10_skolkovo_report.txt §3.9.2]` | Единичная запись в БД; можно копировать и пере-котировать |
| **КБМ** | Коэффициент бонус-малус — история аварийности водителя `[ист: 08_module_osago.txt]`. **Берётся из внешнего источника** (ApiCloud / РСА), не считается локально `[ист: 11_service_autoassistant.txt §3]` | В прототипе-моке приходит как поле `kbm` в `OwnerInfo` |
| **Скоринг** | Оценка рисков и надёжности клиента `[ист: 08_module_osago.txt]` | Внутренний скоринг AA перед отправкой в СК: чёрные списки, профили, сегментация |
| **Тариф** | Ответ СК с ценой полиса по котировке | |
| **Премия** | Стоимость полиса (сумма к оплате страхователем) | Не путать с КВ агента |
| **Страховая сумма** | Лимит покрытия (для «Здоровья» настраивается) | |
| **[Г] Полная формула ОСАГО** | ТБ × КТ × КБМ × КВС × КМ × КО (+ КС, КП, КН) — отраслевая (Указание ЦБ) | В документах легаси полная формула **не приведена**; расчёт делают СК/РСА. См. [03 §5](./03-osago.md) и [13, Q2](./13-open-questions.md) |

## Сегмент, пул, переходы

| Термин | Определение | Комментарий — **несущая ось логики продаж** |
|--------|-------------|---------------------------------------------|
| **Сегмент** | 1) Открытая для страхования территория/условия, по которым СК даёт прямое одобрение. 2) Также — гео-фокус сервиса (Сибирь/ДВ) `[ист: 08_module_osago.txt, 06_ms_segmentation.txt]` | В сегменте ОСАГО можно оформить **без кросс-продукта** |
| **Пул / Перестрахование** | Перестраховочный пул (РСА/НСИС). Куда уходит риск, если на сегмент нет одобрения СК `[ист: 08_module_osago.txt «Пул», 11_service_autoassistant.txt]` | В пуле кросс-продукт **обязателен**; продукт называется «Автопомощник» |
| **Автопомощник** | Услуга оформления ОСАГО через РСА-пул, когда СК не одобрили сегмент `[ист: 11_service_autoassistant.txt]` | Отдельная оплата услуги; дооформление сотрудником СК. См. [06](./06-autoassistant.md) |
| **Зелёный переход** | Смена СК с сохранением непрерывности страхования без ухудшения условий `[ист: 08_module_osago.txt]` | Влияет на выбор СК при расчёте |
| **Новый бизнес** | Оформление нового полиса клиенту без действующего/подходящего для продления `[ист: 08_module_osago.txt]` | |
| **Продление / Пролонгация** | Повторное заключение договора на новый период `[ист: 09_module_renewal.txt]` | См. [05](./05-renewal.md) |
| **Открытость территории** | Разрешено ли страхование по адресу регистрации собственника (проверка сегментации) `[ист: 06_ms_segmentation.txt §2.2.1]` | Первый шаг сегментации |

## Финансы

| Термин | Определение |
|--------|-------------|
| **КВ (Комиссионное вознаграждение)** | Вознаграждение агента за оформленный полис `[ист: 10_skolkovo_report.txt §3.7]`. Зависит от типа продукта, **сегмента vs пула**, месячного объёма продаж агента. **На экранах котировок в ₽ не показываем** (политика, CLAUDE.md) |
| **Проникновение кросс-продуктов** | Доля допов к основным полисам (метрика эффективности кросс-продаж) `[ист: 10_skolkovo_report.txt §3.7]` |
| **Кросс-продукт (доп)** | Дополнительный продукт к основному (Юрист, НС при ДТП, МиниКАСКО, Надёжная поездка) `[ист: 11_service_autoassistant.txt]` |
| **Хороший портфель / убыточность** | Доля «хороших» котировок по методологии AA; контроль убыточности в разрезе СК `[ист: 10_skolkovo_report.txt §3.8]` |
