# 06. Услуга «Автопомощник» (перестраховочный пул)

> Источник: `11_service_autoassistant.txt`, сверка `08_module_osago.txt`, `10_skolkovo_report.txt`.
> Контекст: продолжение **Policy Administration** (ветка «нет одобрения в сегменте») + **Billing** (отдельная оплата услуги).

## 1. Что это и когда включается

**[Ф]** «Автопомощник» — способ оформить ОСАГО через **перестраховочный пул РСА**, когда СК-партнёры **не дали одобрения на сегмент** `[ист: §1]`.

Триггер (из ответов СК):
```
Расчёт ОСАГО → СК не одобрили сегмент
   → система запрашивает у РСА список сегментов, одобренных для пула
   → сопоставляет данные клиента с одобренными сегментами
   → формирует список СК, готовых дать предложение в пуле
   → показывает агенту предложения «в НЕ сегмент» = РСА-Автопомощник
```
`[ист: §1, §1.1]`

**Связь с сегментацией:** это ветка «нет одобрения» из общего скоринг-флоу (см. [08](./08-segmentation.md), [03 §4](./03-osago.md)).

## 2. Обязательный кросс-продукт `[ист: §1.1]`

**[Ф]** В пуле продать «голый» ОСАГО **нельзя** — обязателен кросс-продукт `[ист: §1.1, 08_module_osago.txt ФТ-28]`. Настройки кросс-продуктов **гибкие**:
- Какой доп обязателен при оформлении в пул — настраивается на профиле агента.
- **Цена допа может зависеть от КБМ** `[§1.1]`.
- Можно привязать цену/доп к конкретной СК, разрешить продажу без допа, задать желаемую цену допа.

> Это **главная маржа** (кросс-продажи). В прототипе на странице договора можно докупить до 3-го допа; при оплате ОСАГО — только 1 (память `project_contract_page_value`). Но **сама ось «сегмент/пул» в прототипе не смоделирована** — обязательность допа в пуле нигде не форсится. См. [12](./12-gaps-vs-prototype.md).

## 3. Оплата услуги `[ист: §2]`

**[Ф]** При оформлении в пул **клиент оплачивает стоимость услуги отдельно** `[§2]`. Для получения доп. услуг ДС **переводятся на выделенный номер телефона** `[§2]`.

> **[П]/риск.** «ДС на выделенный номер телефона» — нестандартная платёжная механика (не эквайринг). Для нового фронта нужно понять: это операционная деталь бэк-офиса или элемент UX агента? См. [13, Q8](./13-open-questions.md). Это **Billing-контекст** и требует аккуратного аудита (152-ФЗ, финоперации).

## 4. Дооформление (сотрудник СК) `[ист: §2.1, §2.2]`

**[Ф]** У пула — **двухстадийное завершение**. «Ответственные пользователи» (сотрудники СК) имеют отдельный инструмент дооформления:
1. Указать **номер договора**.
2. Ввести **сумму**.
3. Выбрать **СК**.
4. Прикрепить документы (**заявление + полис**).
5. → договор переходит в статус **«Оформленный»**.

**Смысл для агента:** после отправки в пул полис **не готов мгновенно** — есть промежуточное состояние «Оформляется», пока сотрудник СК не дооформит. Это соответствует статусу котировки «Оформляется» ([03 §8](./03-osago.md)).

## 5. Коэффициенты `[ист: §3]`

**[Ф]** Все коэффициенты стоимости «Автопомощника» — **внутренние** (разрабатывают специалисты AA на основе тарифов), **кроме КБМ**, который берётся из **ApiCloud** `[§3]`.

## 6. BPMN-словами (участники и шаги)

```
Агент ──[Рассчитать ОСАГО]──► Система AA
Система AA ──[котировки]──► СК-партнёры
СК-партнёры ──[нет одобрения сегмента]──► Система AA
Система AA ──[запрос одобренных сегментов]──► РСА/НСИС
Система AA ──[список СК в пуле + обязат. доп]──► Агент
Агент ──[выбор + оплата ОСАГО + доп + услуга]──► Эквайринг / выделенный номер
Система AA ──[договор в статусе «Оформляется»]──► очередь дооформления
Сотрудник СК ──[дооформление: №, сумма, СК, документы]──► статус «Оформленный»
Система AA ──[документы клиенту]──► Dashamail (email)
```

## 7. Исключения (Коберн)

| Ситуация | Комментарий |
|----------|-------------|
| **Оплатили услугу, дооформление зависло** | Полис в «Оформляется» неопределённо долго. Нужен SLA/статус/уведомление агенту |
| **РСА/НСИС не вернула одобренные сегменты** | Тупик: ни сегмент, ни пул. Понятный отказ агенту |
| **Доп не выбран, но пул обязателен** | Блокировать «Продолжить» до выбора допа |
| **КБМ поменялся между расчётом и оплатой** | Цена допа (зависит от КБМ) «прыгает» — фиксировать на момент котировки |
| **Возврат при расторжении полиса из пула** | Как считается возврат услуги «Автопомощник» отдельно от премии? В легаси не описано — [13, Q9](./13-open-questions.md) |
