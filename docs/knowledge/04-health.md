# 04. Модуль «Здоровье»

> Источник: `07_module_health.txt` (модуль «Здоровье», ФТ-1…ФТ-17, ПИ-1…ПИ-10), сверка `10_skolkovo_report.txt §3.10`.
> Контекст: **Policy Administration**. Оплата — [07](./07-payments.md).

## 1. Продукты `[ист: ФТ-1]`

| Продукт | Что покрывает | Расчёт | Печатные формы | Оплата |
|---------|---------------|--------|----------------|--------|
| **НС универсальный** (НС индивидуальный) | Риски НС в повседневной жизни | **Калькулятор на платформе AA** `[ФТ-2]` | На стороне AA, реестровая схема, авто-номера сертификатов `[ФТ-3, ФТ-4]` | **Best2Pay** `[ФТ-12]` |
| **НС спорт** | Травмы/НС при занятиях спортом | Калькулятор AA `[ФТ-2]` | На стороне AA | Best2Pay |
| **Антиклещ** | Последствия укуса клеща (диагностика/лечение) | **API СК: Ренессанс, Согласие, Югория** `[ФТ-2]` | **На стороне СК** `[ФТ-4]` | **Эквайринг СК** (Согласие, Югория) `[ФТ-13]` |

**Ключевая асимметрия для архитектуры:** НС спорт/универсальный — **наш расчёт и наш документ**; Антиклещ — **чужой расчёт и чужой документ** (СК). Это два разных интеграционных паттерна на одном экране.

> **Прототип** реализует «Здоровье» как 3 карточки-селектора (НС / Спорт / Клещ), флоу как ОСАГО (форма → лоадер → котировки → оплата → договор). Скидка клиенту подписана «Скидка из комиссии» (0 / −15%); у части СК цена фиксированная (Антиклещ — Ренессанс). См. память `project_quote_screen_conventions`.

## 2. Форматы: индивидуальный / коллективный `[ист: ФТ-5…ФТ-9]`

- Переключатель **Индивидуальный / Коллективный** `[ФТ-8]`.
- **Коллективный**: группа **от 2 до 50** застрахованных `[ФТ-5, ФТ-7]`.
- При коллективном — выбор категории: **Дети / Взрослые / Дети и взрослые**, и количество через **ползунок 0–50** отдельно для детей и взрослых `[ФТ-8, ФТ-9]`.

### Возрастные ограничения `[ист: ФТ-5, ФТ-7, §3.10]`

| Продукт | Ребёнок | Взрослый |
|---------|---------|----------|
| НС спорт / НС универсальный | 2–16 лет | 16–70 лет |
| Антиклещ | 0–18 лет | 18–100 лет |

> **Внимание:** границы разные у НС и Антиклеща и **пересекаются на 16/18**. При проектировании валидации не унифицировать — брать по продукту.

## 3. НС спорт — виды спорта `[ист: ФТ-6]`

- Выпадающий список из справочника **«Виды спорта»**.
- **Не более 3 видов спорта** (галочки), система подтверждает лимит.

## 4. Сроки и даты `[ист: ФТ-10, ФТ-11]`

- Срок страхования — **1 год** для всех продуктов `[ФТ-10]`.
- Дата начала:
  - **НС спорт / НС универсальный — +1 день** от текущей `[ФТ-11]`.
  - **Антиклещ — +4 дня** от текущей (период ожидания) `[ФТ-11]`.
- Дата окончания = дата начала + 1 год.

## 5. Изменяемые параметры до «Рассчитать» `[ист: ФТ-15]`

- Дата начала страхования.
- **Страховая сумма**.
- Количество детей/взрослых (коллективный).

## 6. Данные страхователя и застрахованных `[ист: ФТ-16, ПИ-7, ПИ-9]`

**Страхователь:** ФИО, дата рождения, паспорт (серия/номер, дата выдачи, **кем выдан**), телефон, email.

**Застрахованный:** ФИО, дата рождения; отображается столько форм, сколько застрахованных указано.
- Чекбокс **«Страхователь = Застрахованный»** → автозаполнение раздела «Застрахованный 1», поля блокируются, снятие — очищает `[ПИ-9]`.

**Коллективный полис — загрузка списка** `[ФТ-17, ПИ-10]`:
- Скачать **Excel-шаблон** → заполнить (ФИО, дата рождения) → загрузить → автозаполнение форм. Либо ручной ввод.

## 7. Пользовательский путь `[ист: §3.10.3]`

```
1. Авторизация → раздел «Здоровье» (иконка «Сердце»)
2. Выбор продукта переключателем (НС универсальный / НС спорт / Антиклещ)
3. (НС спорт) выбор до 3 видов спорта
4. (Коллективный) категория + количество ползунками
5. Проверка страховой суммы и даты начала → «Рассчитать»
6. Модальное окно с тарифом: страховая сумма, срок, премия, даты, СК, скидки [ПИ-5]
7. Выбор тарифа → данные страхователя (+ застрахованные / Excel)
8. Оплата картой [07]
9. «Полис оформлен» → скачать (стрелка вниз)
```

## 8. Модальные окна `[ист: ПИ-5, ПИ-6]`

- **Тарифы**: страховая премия, стоимость в ₽, даты начала/окончания, страховая сумма, название СК, доп. предложения со скидками.
- **Оплата**: форма карты (номер, срок, CVV), «Оплатить», общая стоимость.

## 9. Исключения (Коберн)

| Ситуация | Комментарий |
|----------|-------------|
| **Антиклещ: СК не ответила** | Расчёт зависит от API Ренессанс/Согласие/Югория — таймаут на 3G, нужен `failedCompanies`/частичный показ |
| **Коллективный: битый Excel** | Валидация загруженного файла (формат ФИО/дат), понятная ошибка. В легаси не описано |
| **Двойная оплата** | Best2Pay — идемпотентность, как в [07](./07-payments.md) |
| **Возраст вне границ** | Валидация по продукту (см. §2); нельзя добавить в полис |
| **> 3 видов спорта / > 50 человек** | Жёсткие лимиты, блокировать на форме |
| **Печать сертификата НС** | Формируется на стороне AA (реестровая схема) — при недоступности сервиса печати полис оформлен, но документа нет; нужна повторная генерация |

## 10. Открытые вопросы по «Здоровью»
- **[П]** Тарифная сетка НС (калькулятор AA): от чего зависит премия (возраст, страховая сумма, виды спорта)? В документах — только «страховая сумма и срок». → [13, Q7](./13-open-questions.md).
- **[П]** «Скидка из комиссии» (0 / −15%) — бизнес-правило прототипа; в легаси-документах явно не описано. Подтвердить тиры и правила.
