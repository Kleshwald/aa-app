# Agent Academy — согласованные прототипы от 03.11.2026

Откройте `index.html`. Все страницы — самодостаточные HTML-прототипы с встроенными стилями и JavaScript.

## Состав

1. Мои клиенты — `Agent-Academy-OSAGO.html` (существующий базовый прототип).
2. Мои агенты — `Agent-Academy-My-Agents-outline.html` (белая кнопка с синим контуром).
3. Продление полисов — `Agent-Academy-Prolongation.html`.
4. Аналитика — `Agent-Academy-Analytics.html`.
5. Мои результаты — `Agent-Academy-My-Results.html`: результаты, договорённости, к выплате, история выплат.
6. ОСАГО — `Agent-Academy-OSAGO-journey.html`: оформление → расчёт → оплата → финальная форма договора с документами и заявками.

Финальная форма включена в процесс ОСАГО, отдельного пункта для неё нет. Переключатель в финальной форме показывает варианты ОСАГО + доп, ОСАГО ЮЛ, здоровье и ипотека.

## Проверка

- Из каталога откройте каждую из шести страниц.
- В ОСАГО используйте заполнение демонстрационными данными и пройдите оформление до финальной формы.
- В финальной форме проверьте переключение продуктов, выбор документов, просмотр и добавление комментариев.
- Для ОСАГО ЮЛ проверьте ожидание оплаты и выбор транспорта для договора и акта.

Нет подключения к 1С, страховым компаниям, почте или платежам. Заявки и комментарии не отправляются; скачиваемые примеры не являются страховыми документами. Полный рабочий сценарий показан для ОСАГО; остальные продукты представлены вариантами финальной формы. Исторические дубли и архивы не входят в этот набор.

Файл `docs/polis-osago-demo.pdf` — существующий демонстрационный PDF из репозитория, используемый базовыми страницами.
